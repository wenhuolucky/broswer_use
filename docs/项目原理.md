# 项目原理详解

## 一、整体定位

本项目是一个**基于 AI Agent 的浏览器自动化工具**，包含两个独立模块：

1. **头条号自动发布** — 模拟人类操作 Edge 浏览器完成头条号文章发布
2. **豆包循环问答** — 自动向豆包发送问题并收集回复，测试 AI 检测性

核心能力：
- 登录目标网站（保存 cookie）
- AI Agent 自主操作浏览器完成任务
- 随机延迟和行为模拟降低风控风险

---

## 二、技术框架

本项目使用了 **3 个主要框架**，层层嵌套、各司其职：

```
┌─────────────────────────────────┐
│  高层：browser-use（框架核心）     │
│  负责：AI 决策循环 + 浏览器调度    │
│  代码位置：publisher.py Agent    │
└──────────────┬──────────────────┘
               │
┌──────────────▼──────────────────┐
│  中层：DeepSeek（大语言模型）       │
│  负责：分析页面 → 决策下一步动作   │
│  代码位置：publisher.py get_llm() │
└──────────────┬──────────────────┘
               │
┌──────────────▼──────────────────┐
│  底层：Playwright（浏览器控制）   │
│  负责：启动 Edge 浏览器、执行操作动作 │
│  代码位置：browser_utils.py       │
└─────────────────────────────────┘
```

### 2.1 Playwright — 底层浏览器控制

**职责**：启动和管理本地 Edge 浏览器，通过 Chrome DevTools Protocol (CDP) 向浏览器下达指令。

**启动方式**：

```python
from playwright.async_api import async_playwright

playwright = await async_playwright().start()
ctx = await playwright.chromium.launch_persistent_context(
    user_data_dir=str(user_data_dir),
    headless=False,
    executable_path=get_edge_path(),
    args=[f"--remote-debugging-port={cdp_port}"],
    viewport={"width": 1280, "height": 900},
)
```

关键参数：
- `user_data_dir`：浏览器用户数据目录，保存登录态和历史记录
- `executable_path`：指定 Edge 浏览器可执行文件路径
- `args`：CDP 调试端口，用于后续 Agent 连接控制

### 2.2 DeepSeek — AI 决策大脑

**职责**：接收页面状态 + 任务指令，返回"下一步做什么"的决策。

本项目使用 `ChatOpenAILike` 适配器来调用 DeepSeek，格式上与 OpenAI API 兼容：

```python
llm = ChatOpenAILike(
    model="deepseek-chat",              # 使用 DeepSeek Chat 模型
    base_url="https://api.deepseek.com/v1",
    api_key=os.getenv("DEEPSEEK_API_KEY"),
    dont_force_structured_output=True,
    add_schema_to_system_prompt=True,
)
```

**本质**：DeepSeek 并不是"看到"浏览器窗口，它收到的是 browser-use 整理好的**页面结构化文本**（DOM 快照），然后返回类似 `click index:52` 或 `input text:xxx` 的动作指令。

### 2.3 browser-use — 串联层（框架核心）

**职责**：
1. 读取当前页面的 DOM 树 → 压缩为结构化文本
2. 将文本 + 任务指令 → 发送给 DeepSeek API
3. DeepSeek 返回动作 → 通过 Playwright 执行
4. 循环以上步骤直到 Agent 认为任务完成

**核心代码**：

```python
agent = Agent(
    task=task,                    # 自然语言任务指令
    llm=llm,                      # DeepSeek 模型
    browser_session=session,      # Playwright 管理的浏览器会话
    use_vision=False,             # 不使用视觉（纯 DOM 分析）
    max_actions_per_step=3,       # 每步最多 3 个动作
    max_failures=5,               # 允许 5 次失败后重试
    step_timeout=120,             # 每步超时 120 秒
    available_file_paths=[...],   # 允许上传的文件路径
)
history = await agent.run(max_steps=80)
```

## 三、Agent 是如何工作的

### 3.1 每一步的完整循环

```
┌─────────┐   1. 读取DOM    ┌──────────────┐
│ 浏览器  │ ──────────────▶ │ browser-use │
│ (Playwright)│◀──────────── │ (Agent)     │
└─────────┘   2. 执行动作   └──────┬───────┘
                                   │
                    3. 发送 DOM 快照 + task
                                   ▼
                            ┌──────────────┐
                            │  DeepSeek    │
                            │  (LLM)       │
                            └──────┬───────┘
                                   │
                    4. 返回动作指令
                                   ▼
                            "click index:52"
                            "input text:标题"
                            "scroll down"
```

### 3.2 DOM 快照是什么

browser-use 不截图，它读取的是**页面的 DOM 结构**。每个元素有一个编号（index），DeepSeek 根据任务指令决定"index 52 是发布按钮，应该点击它"。

### 3.3 如何构造任务指令（Task）

`task` 是一段**自然语言指令**，告诉 Agent 要做什么：

```python
task = f"""你在头条号后台(mp.toutiao.com)操作。请按顺序完成以下步骤来发布一篇文章：

1. 首先导航到: {TOUTIAO_HOME}
2. 确认已登录后台。如果看到登录页面，停止并提示用户重新 --setup 登录。
3. 导航到发布文章页面: {TOUTIAO_PUBLISH_URL}
4. 等待页面加载完成。
5. 找到文章标题输入框，输入标题: "{title}"
6. 找到文章正文编辑区域，输入以下内容:
   <content>
   {content}
   </content>
7. 设置封面图片（严格按顺序）：
   - 第1步：在封面设置区域，找到并点击"+"号图标
   - 第2步：弹出对话框后点击"本地上传"
   - 第3步：使用 file input 上传: {abs_cover_path}
   - 第4步：等待封面预览显示
8. 检查分类等必填项是否缺失。
9. 点击"发布"按钮。如果弹出确认对话框，点击确认。
10. 确认文章发布成功。
"""
```

**关键点**：
- `content` 内容用 `<content>` XML 标签包裹，防止内容中的特殊字符干扰 LLM 的指令解析
- 封面流程拆成 4 个**非常具体的步骤**，避免 Agent 陷入模糊指令循环
- 图片 URL 通过指令传递，Agent 负责在正文中插入 `<img>` 标签

### 3.4 available_file_paths 安全机制

browser-use 有一个安全限制：**Agent 只能上传在 `available_file_paths` 中预先注册过的文件**。

```python
available_files = []
if cover_local_path:
    available_files.append(str(Path(cover_local_path).absolute()))

agent = Agent(
    ...
    available_file_paths=available_files if available_files else None,
)
```

如果文件路径没有注册，Agent 会拒绝上传。

## 四、图片上传流程详解

### 4.1 为什么分两种上传方式

| 场景 | 触发方式 | 自动化难度 |
|---|---|---|
| **正文图片** | 点击工具栏图片按钮 → 弹出抽屉 → file input | 可以预上传（Playwright 直接操作 DOM） |
| **封面图片** | 点击"+" → 弹出选择框 → 点"本地上传" → 文件对话框 | 需要 Agent 通过完整 UI 流程上传 |

### 4.2 正文图片预上传流程（完全自动化）

```
1. toutiao_uploader.py 启动无头 Edge 浏览器，加载 auth.json
2. 导航到发布页面 https://mp.toutiao.com/profile_v4/graphic/publish
3. 点击工具栏第 12 个按钮 (.syl-toolbar-button:nth(11))
4. 弹出图片上传抽屉 (.mp-ic-img-drawer)
5. Playwright 直接设置: page.locator('input[type="file"]').first.set_input_files(image_path)
6. 头条号 CDN 返回图片 URL
7. 关闭浏览器，返回 URL 列表给 publisher.py
```

### 4.3 封面图片上传流程（Agent 介入）

封面图片通过 Agent 的 `upload_file` 动作上传，严格按步骤执行：
- 点击封面区域的 "+" 号图标
- 对话框弹出后，点击"本地上传"按钮
- 触发隐藏的 file input 元素
- Agent 执行 upload_file 动作上传本地文件
- 等待封面上传完成，预览显示

## 五、完整发文流程示例

以命令 `python publisher.py --publish --title "中华田园犬" --content-file article.txt --images 1.png 2.png 3.png` 为例：

### 第一阶段：准备（publisher.py）

```
1. 解析命令行参数，读取 article.txt 内容
2. 分离图片列表：[1.png, 2.png, 3.png]
   - 1.png → cover_local_path（封面，保留本地路径）
   - [2.png, 3.png] → body_image_urls（正文，预上传）
3. 调用 upload_images() → 预上传 2.png 和 3.png → 获得 CDN URL 列表
4. 构造 task 指令（包含标题、正文、封面路径、正文图片 URL）
5. 启动 Edge 浏览器（launch_persistent_context + CDP 端口）
6. 创建 Agent（绑定 DeepSeek + 注册封面文件路径）
```

### 第二阶段：Agent 执行（browser-use 循环）

```
Step 1:  导航到 mp.toutiao.com
Step 2:  检查登录状态（cookie 有效）✓
Step 3:  导航到发布页面 https://mp.toutiao.com/profile_v4/graphic/publish
Step 4:  等待页面加载
Step 5:  点击标题输入框 → 输入 "中华田园犬"
Step 6:  点击正文区域 → 输入文章全文
Step 7:  在正文中插入 2 张图片的 <img> 标签
Step 8:  点击封面区域 "+" 号图标
Step 9:  点击"本地上传" → 弹出文件对话框
Step 10: upload_file(index:xxx, path:1.png) 上传封面
Step 11: 等待封面上传完成，预览显示
Step 12: 检查必填项（分类等）
Step 13: 点击"预览并发布"
Step 14: 弹出确认对话框 → 点击"确认发布"
Step 15: 页面显示 "发布成功" → Agent 调用 done() 完成任务
```

### 第三阶段：收尾

```
1. Agent 报告完成，打印结果
2. BrowserSession 关闭 + Playwright 停止
3. publisher.py 打印最终结果，写入 result/ 目录
```

## 六、与 computer-use 的区别

browser-use 和 computer-use 名字相似，但原理完全不同：

| | browser-use（本项目） | computer-use |
|---|---|---|
| **感知方式** | 读取页面 DOM 树 | 分析屏幕截图（像素） |
| **操作精度** | 精确到 DOM 元素 index | 依赖视觉识别，可能点偏 |
| **速度** | 快（DOM 分析快） | 慢（每次都要截图分析） |
| **依赖** | 只需要页面结构不变 | 需要页面 UI 视觉特征稳定 |
| **本项目用途** | ✅ 核心框架 | ❌ 未使用 |

## 七、豆包循环问答模块

### 7.1 工作流程

```
1. 启动 Edge 浏览器：
   - 方案 A：脚本自动启动（_launch_edge，含启动参数反检测 + 注入 Stealth JS）
   - 方案 B（推荐）：用户手动启动 doubao/start_edge.bat，脚本只通过 CDP 附加
2. 脚本通过 CDP 连接浏览器，注入运行时 Stealth JS（覆盖 navigator.webdriver 等）
3. 每轮迭代：
   a. 随机选择问题（11 类：事实/推理/创造/观点/技术/数学/科学/历史/生活/语言/AI 探测）
   b. Agent 操作浏览器：导航到 doubao.com/chat → 随机行为（滚动/鼠标/停留）→ 点击新对话 → 输入问题 → 发送
   c. 等待回复，提取内容
   d. 随机延迟 1-5 秒（人类行为模拟）
   e. 等待间隔时间（建议 ≥ 120 秒）后进行下一轮
4. 每条记录写入 JSONL 文件（按日期分文件）
```

### 7.2 五层反检测机制

| 层级 | 手段 | 检测绕过 |
|---|---|---|
| **启动参数** | `--disable-blink-features=AutomationControlled`、`ignore_default_args=["--enable-automation"]` | 移除 `navigator.webdriver=true` + 地址栏"自动测试"提示 |
| **启动注入** | `add_init_script(_STEALTH_INIT_SCRIPT)` | 页面加载前覆盖 `webdriver`、伪造 `plugins`/`languages`、清理 `cdc_` 变量 |
| **CDP 注入** | `Runtime.evaluate(stealth_js)` 通过 CDP 向已运行进程注入 | 手动启动 Edge 同样被覆盖自动化痕迹 |
| **行为模拟** | 随机滚动/鼠标/停留（5 种）+ 1-5s 随机延迟 | 打破固定节奏，模拟人类操作模式 |
| **手动启动** | 用户双击 `start_edge.bat`，脚本只 CDP 附加 | 绕过 Playwright 启动全流程，自动化痕迹最少 |

### 7.3 数据存储

- 格式：JSONL（每行一条记录，JSON 格式）
- 文件：`doubao/data/doubao_qa_YYYYMMDD.jsonl`（按日期分文件）
- 字段：timestamp、question_index、question、response、response_length、response_time_ms、error、iteration、total_seconds

## 八、项目文件结构

```
publisher.py              — 头条号主程序（CLI + 发文流程控制 + Agent 构建）
concurrent_publisher.py   — 多用户并发发布管理器
user_manager.py           — 多用户配置和锁管理
browser_utils.py          — 共享工具（Edge 路径检测 + CDP URL 获取）
toutiao_uploader.py       — 图片预上传模块（Playwright 无头上传）
users.yaml                — 多用户配置文件
auth.json                 — 头条号登录 cookie（自动生成）
.env                      — API Key（需自己配置）

doubao/doubao_tester.py   — 豆包循环问答主程序
doubao/browser_session.py — 豆包浏览器会话管理
doubao/questions.py       — 测试问题库
doubao/storage.py         — JSONL 数据存储
doubao/human_behavior.py  — 人类行为模拟（随机延迟）
```

**数据流**：

```
命令行参数
    │
    ▼
publisher.py (main)
    │
    ├───▶ read content-file  ──▶ article.txt 内容
    │
    ├───▶ toutiao_uploader.upload_images()  ──▶ CDN URL 列表
    │
    └───▶ Agent(task + llm + session)
              │
              ├──▶ DeepSeek (决策)
              └───▶ BrowserSession (Playwright 控制 Edge 浏览器)
```
