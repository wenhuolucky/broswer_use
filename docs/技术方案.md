### 5.2 转换实现

**文件:** `publish_service/markdown_to_rich.py`

```python
import markdown

def markdown_to_html(markdown_text: str) -> str:
    """
    将 Markdown 转换为 HTML 富文本

    输入: Markdown 格式字符串
    输出: HTML 格式字符串

    支持的格式:
    - 标题 (# ## ###)
    - 加粗 (**text**)
    - 斜体 (*text*)
    - 链接 [text](url)
    - 图片 ![alt](url)
    - 列表 (- item)
    - 代码块 (`code`)
    - 引用 (> quote)
    """
    html_content = markdown.markdown(
        markdown_text,
        extensions=[
            'nl2br',       # 换行转 <br>
            'tables',      # 表格
            'del',         # 删除线
            'fenced_code', # 代码块
        ]
    )
    return html_content
```

## 七、头条号发布详细流程

### 7.1 Agent Prompt 结构

**文件:** `platforms/toutiao.py`

当检测到 Markdown 并已转换为 HTML 时，使用以下 prompt：

```python
prompt = """
请按顺序完成以下步骤来发布一篇文章：

1. 导航到: https://mp.toutiao.com
2. 确认已登录，读取账号名

3. 导航到: https://mp.toutiao.com/profile_v4/graphic/publish

4. 输入标题: "文章标题"

5. 注入富文本 HTML:
   使用 evaluate 执行 JavaScript:
   const editor = document.querySelector('[contenteditable="true"]');
   editor.innerHTML = `<html_content>`;
   editor.dispatchEvent(new Event('input', { bubbles: true }));

6. 设置封面（如需要）

7. 点击"预览并发布"

8. 调用 done 返回结果
"""
```

### 7.2 富文本注入原理

#### 7.2.1 问题背景

头条号编辑器是一个 `contenteditable` 元素，无法通过 `send_keys` 直接输入带格式的文本。

#### 7.2.2 解决方案

通过 JavaScript 直接操作 DOM：

```javascript
// 获取编辑器元素
const editor = document.querySelector('[contenteditable="true"]');

// 设置焦点
editor.focus();

// 直接设置 HTML 内容
editor.innerHTML = `
  <h1>文章标题</h1>
  <p>这是一个<strong>加粗</strong>和<em>斜体</em>的段落。</p>
  <ul><li>列表项1</li><li>列表项2</li></ul>
`;

// 触发 input 事件让编辑器更新状态
editor.dispatchEvent(new Event('input', { bubbles: true }));
```

#### 7.2.3 为什么不用剪贴板？

1. **并发安全问题**: 系统剪贴板是共享资源，多用户会互相覆盖
2. **HTML 格式丢失**: 普通剪贴板复制可能丢失格式
3. **CDP 稳定性**: 通过 CDP 执行 JavaScript 是浏览器原生的操作，最可靠

### 7.3 发布步骤详解

```
步骤 1: 导航到头条号后台
├── 操作: await session.navigate("https://mp.toutiao.com")
├── 验证: 检查页面是否包含登录态（检查 Cookie）

步骤 2: 读取账号名
├── 操作: 查找页面元素（如右上角用户名）
├── 记录: account_name

步骤 3: 导航到发布页面
├── 操作: await session.navigate("https://mp.toutiao.com/profile_v4/graphic/publish")
├── 验证: 检查是否到达编辑页面

步骤 4: 输入标题
├── 操作: 查找 input 元素并 fill()
├── 命令: await session.fill("input[placeholder*='标题']", title)

步骤 5: 注入富文本
├── 操作: 执行 JavaScript evaluate
├── 命令: await session.evaluate(js_code)
└── JS内容: editor.innerHTML = html_content

步骤 6: 设置封面
├── 操作: 点击 + 号 → 本地上传 → file input
├── 命令: await session.set_input_files(input, cover_path)

步骤 7: 预览并发布
├── 操作: 点击"预览并发布"按钮
├── 等待: 弹出确认对话框
├── 操作: 点击"确认发布"按钮
└── 验证: 检查页面变化确认发布成功

步骤 8: 返回结果
├── 操作: agent.done()
└── 格式: {"success": true/false, "account_name": "...", "article_url": ""}
```

## 十一、并发安全设计

### 11.1 问题分析

| 资源 | 原方案问题 | 解决方案 |
|------|------------|----------|
| 系统剪贴板 | 多用户互相覆盖 | 使用 `innerHTML` 直接注入 |
| 临时文件 | request_id 隔离 | 使用 `request_id` 前缀 |
| CDP 端口 | 独立浏览器实例 | 每个用户独立 Playwright context |

### 11.2 当前安全机制

1. **HTML 注入替代剪贴板**: 每个用户的富文本内容直接通过 JavaScript 注入，不经过系统剪贴板
2. **独立浏览器上下文**: 每个 `launch_persistent_context` 创建独立的浏览器实例和用户数据目录
3. **Request ID 隔离**: 所有日志、临时文件都使用唯一的 request_id 标识
